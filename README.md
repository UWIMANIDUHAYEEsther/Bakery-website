# Bakery Website

A responsive multi-page bakery website built with HTML5 and CSS3. The website provides a clean and user-friendly interface for showcasing bakery products, images, information, and contact details.

## Features

* Responsive design for different screen sizes
* Multi-page website navigation
* Bakery products/menu section
* Image gallery
* FAQ section
* Contact form
* Registration page
* Blog page
* Responsive navigation
* Font Awesome icons
* Clean and organized HTML and CSS

## Technologies Used

* HTML5
* CSS3
* Font Awesome

## Pages

The website includes:

* Home
* About
* Products
* Gallery
* FAQ
* Contact
* Register
* Blog

[View the live website](https://uwimaniduhayeesther.github.io/Bakery-website/)

## Purpose

This project was created to practice and demonstrate skills in building responsive, multi-page websites using HTML5 and CSS3.
